# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately through GitHub: open the **Security** tab of this repository and choose
**Report a vulnerability** (private security advisory). Include the affected version or commit,
steps to reproduce, and the impact you expect.

You will get a reply in the advisory thread. Fixes are released on the default branch.

## Supported versions

Only the latest commit on the default branch is supported.
